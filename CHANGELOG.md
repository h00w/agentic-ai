# Changelog

All notable changes to **Agentic AI Academy** are documented here.

The project follows semantic versioning for public milestones.

## 0.1.0 — 2026-09-12

### Added

- Launch Agentic AI Academy as an open-source curriculum and engineering reference platform.
- Add 14 curriculum modules spanning foundations, Python, agent engineering, tools, RAG, multi-agent systems, evaluation, security, production, observability, governance, enterprise architecture, and AI leadership.
- Add six role-based learning pathways for beginners, Python developers, AI/ML engineers, product managers, architects/technical leaders, and researchers.
- Add ten enterprise case studies and ten progressive portfolio projects.
- Add the **Responsible Enterprise Research Agent** flagship capstone and assessment rubric.
- Add 11 deterministic, beginner-friendly runnable examples that require no external API keys.
- Add a framework-neutral Python reference implementation under `src/agentic_ai/`.
- Add reusable evaluation infrastructure for task success, correctness, groundedness, tool accuracy, safety, latency, token usage, and estimated cost.
- Add security architecture, production readiness controls, risk register, governance checklist, deployment playbook, and defense-in-depth guidance.
- Add Docker, CI, tests, configuration examples, documentation checks, and example validation.
- Add Mermaid architecture diagrams and a glossary of Agentic AI terminology.
- Add public deployment templates for Hugging Face Spaces and Streamlit, to be activated in the next deployment phase.
- Add the professional Academy page at `https://hendarmawan.se/agentic-ai/`.
- Add public release notes, roadmap, and citation metadata.
