## What this release establishes

Version 0.1.0 establishes **Agentic AI Academy** as a complete open-source learning and engineering platform for building trustworthy AI agents from first principles through production and enterprise scaling.

The project is intentionally designed to combine five things in one coherent system:

1. a university-quality curriculum,
2. a practical coding bootcamp,
3. a production engineering reference,
4. an enterprise architecture and governance guide,
5. a professional portfolio platform.

## Flagship capstone

### Responsible Enterprise Research Agent

The capstone combines:

- planning
- bounded tool use
- retrieval-augmented generation
- memory
- policy enforcement
- evaluation
- human approval
- cost controls
- failure recovery
- observability
- audit trails

Its purpose is to demonstrate the difference between an impressive agent demo and a trustworthy production-oriented AI system.

## Security principle

Agentic systems must not receive unrestricted capabilities. This release teaches and demonstrates:

- least privilege
- explicit permissions
- defense in depth
- policy gates
- input/output validation
- human approval
- sandbox boundaries
- timeouts
- token/action budgets
- audit logging
- secret management
- safe termination

## Evaluation principle

A visually impressive agent is not necessarily a reliable agent. The Academy evaluates systems across:

- task success
- correctness
- groundedness
- tool accuracy
- safety
- latency
- token usage
- estimated cost
