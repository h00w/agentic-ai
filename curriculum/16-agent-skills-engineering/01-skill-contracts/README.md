# Lesson 16.01 — Skill Contracts and Evidence

## UNDERSTAND

A prompt provides instructions; a skill contract adds bounded purpose, inputs, permissions, failure conditions and evidence expectations.

## BUILD

Review the three starter skills under `skills/` and identify the common capability contract.

## BREAK

Use incomplete or conflicting evidence and requests beyond permissions; the skill should abstain, escalate or reduce the claim.

## MEASURE

Useful skills produce comparable evidence across operators or compatible hosts.

## SECURE

A skill cannot grant itself secrets, production access or side effects. Host authorization remains authoritative.

## SHIP

Retain the skill contract and artifact manifest as reusable evidence.

## OPERATE

Track invocation success, abstention, missing-evidence rate, permission conflicts and version compatibility.

## GOVERN

Version material capability changes and require review when requested permissions, failure behavior or evidence semantics change.
