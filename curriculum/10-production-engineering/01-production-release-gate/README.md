# Lesson 10.01 — Production Release Gate

## UNDERSTAND

Convert capability, safety, reliability and operations evidence into an explicit production-candidate gate.

## BUILD

Assemble release evidence for capability, security, rollback, observability, ownership and change control.

## BREAK

Remove rollback evidence or introduce an unresolved critical finding and verify the release is blocked.

## MEASURE

Every mandatory gate has current evidence and no unresolved blocker remains.

## SECURE

Production eligibility is fail-closed when critical safety/security evidence is missing.

## SHIP

Complete `artifacts/worksheet.md` and retain the artifact manifest as reviewable evidence for this lesson.

## OPERATE

Retain deployment, rollback and incident evidence so production validation can be distinguished from pre-production readiness.

## GOVERN

Document approvers, exception handling and the maximum proof level supported by the evidence.
