# Lesson 08.01 — Evaluation Harness and Release Thresholds

## UNDERSTAND

Translate system claims into test cases, metrics, slices and release thresholds.

## BUILD

Define a compact evaluation plan spanning task success, tool routing, groundedness, safety, latency and cost.

## BREAK

Create a release that passes the average metric but fails a critical safety slice.

## MEASURE

Each release-relevant claim has a metric, threshold, fixture and evidence path.

## SECURE

Safety metrics and critical slices are hard gates rather than weights inside a single average score.

## SHIP

Complete `artifacts/worksheet.md` and retain the artifact manifest as reviewable evidence for this lesson.

## OPERATE

Track regression deltas by model, prompt, tool version and data slice.

## GOVERN

Version thresholds and require an explicit exception process for failed mandatory gates.
