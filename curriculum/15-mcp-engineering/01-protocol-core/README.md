# Lesson 15.01 — MCP Protocol Core and Tool Contract

Define a reviewable tool contract before an SDK implementation.

## BUILD

Inspect `artifacts/tool-contract.example.json`.

## BREAK

Review schema drift, malicious descriptions, silent side-effect changes and out-of-scope capabilities.

## MEASURE

Conformance checks should validate schema, identity, side effects, timeout and authorization metadata.

## SECURE

Treat external MCP descriptions, resources and outputs as untrusted data.
