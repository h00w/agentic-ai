# Module 15: MCP Engineering

Engineer MCP as a protocol, authorization and trust-boundary system rather than a convenience wrapper around tools.

## Roadmap

Protocol core; JSON-RPC; stdio and HTTP transports; lifecycle; tool schemas; resources; prompts; capability discovery; versioning; authentication; authorization; approvals; external-server trust; prompt injection; retries/idempotency; observability; conformance; registry governance; secure MCP gateway capstone.

**Rule:** protocol capability does not grant authority. Identity, policy, approval and audit remain separate deterministic controls.
