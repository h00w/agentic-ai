# Lesson 11.01 — Trace Contract and Correlation IDs

## UNDERSTAND

Design traces that reconstruct model decisions, tool calls, policy gates, budgets and outcomes.

## BUILD

Define a minimal trace event contract and correlation strategy for one end-to-end agent run.

## BREAK

Remove the final side-effecting tool event and determine which audit or incident claims become unsupported.

## MEASURE

A reviewer can reconstruct who/what acted, under which policy, using which budget and with what result.

## SECURE

Exclude secrets and sensitive payloads from traces while preserving decision and authorization evidence.

## SHIP

Complete `artifacts/worksheet.md` and retain the artifact manifest as reviewable evidence for this lesson.

## OPERATE

Measure trace completeness, sampling gaps, error spans, latency, token usage and cost.

## GOVERN

Version trace schemas and define retention/access rules for audit-relevant evidence.
