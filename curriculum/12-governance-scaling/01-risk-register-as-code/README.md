# Lesson 12.01 — Risk Register as Code

## UNDERSTAND

Represent material agent risks as owned, testable controls tied to evidence and release gates.

## BUILD

Create risk entries with scenario, likelihood, impact, control, owner, evidence and review trigger.

## BREAK

Add a high-impact risk without an owner or evidence and show why governance is incomplete.

## MEASURE

Material risks have owners, controls, evidence and explicit residual-risk status.

## SECURE

High-risk permissions and data flows require preventive and detective controls, not narrative acknowledgement alone.

## SHIP

Complete `artifacts/worksheet.md` and retain the artifact manifest as reviewable evidence for this lesson.

## OPERATE

Use incidents, near misses and regressions to update risk likelihood, controls and test coverage.

## GOVERN

Version the register and require review when autonomy, data, tools, models or deployment context materially change.
