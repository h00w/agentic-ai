# Lesson 13.01 — Enterprise Agent Control Plane

## UNDERSTAND

Architect identity, model access, tools, policy, knowledge, evaluation and observability as shared enterprise controls.

## BUILD

Draw the control plane for multiple agent applications while preserving application-specific business logic.

## BREAK

Allow one application to bypass the common policy or audit layer and identify the governance gap.

## MEASURE

Shared controls are consistently enforced while application teams retain bounded extension points.

## SECURE

Centralize identity, policy and sensitive tool admission without centralizing every prompt or business workflow.

## SHIP

Complete `artifacts/worksheet.md` and retain the artifact manifest as reviewable evidence for this lesson.

## OPERATE

Track policy decisions, model/tool versions, shared-service latency and cross-application incidents.

## GOVERN

Define platform ownership, tenancy boundaries, approved extension contracts and evidence responsibilities.
