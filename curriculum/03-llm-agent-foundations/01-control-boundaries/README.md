# Lesson 03.01 — Probabilistic Reasoning, Deterministic Control

## UNDERSTAND

Partition an agent into probabilistic reasoning and deterministic host controls.

## BUILD

Map planning, classification and synthesis separately from identity, policy, budgets, validation, approval and execution controls.

## BREAK

Move one deterministic safety control into a prompt-only instruction and explain what guarantee is lost.

## MEASURE

Every high-impact side effect is mediated by deterministic validation, permission and policy checks.

## SECURE

The model may propose actions; it must not self-assign permissions, budgets or approval.

## SHIP

Complete `artifacts/worksheet.md` and retain the artifact manifest as reviewable evidence for this lesson.

## OPERATE

Trace model decisions and deterministic gate outcomes separately so failures are diagnosable.

## GOVERN

Require review for changes to deterministic control semantics even when prompts or models remain unchanged.
