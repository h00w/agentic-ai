# Lesson 07.01 — Supervisor–Worker Coordination Contract

## UNDERSTAND

Define when multi-agent decomposition adds value and how supervisors constrain workers.

## BUILD

Specify roles, allowed tools, handoff schema, shared state, global budgets and conflict resolution.

## BREAK

Have a worker request an admin-only tool or produce a handoff without required evidence.

## MEASURE

Workers stay within role scopes, handoffs are reconstructable and global budgets cannot be bypassed by parallelism.

## SECURE

Delegation cannot create new permissions; agent messages are not authenticated approvals.

## SHIP

Complete `artifacts/worksheet.md` and retain the artifact manifest as reviewable evidence for this lesson.

## OPERATE

Trace delegation, worker latency, handoff failures, budget use and supervisor replanning.

## GOVERN

Require justification for adding agents and review changes to role authority or shared-state semantics.
