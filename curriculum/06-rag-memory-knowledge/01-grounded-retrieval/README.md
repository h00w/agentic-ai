# Lesson 06.01 — Grounded Retrieval and Evidence Discipline

## UNDERSTAND

Turn retrieval into claim-level evidence rather than a bag of semantically similar text.

## BUILD

Create a claim-to-evidence map with source authority, freshness, conflict and abstention rules.

## BREAK

Introduce a stale authoritative-looking source and an injected instruction inside retrieved content.

## MEASURE

Supported claims map to evidence; unsupported claims abstain; source conflicts remain visible.

## SECURE

Retrieved content is untrusted data and cannot override policy or tool authorization.

## SHIP

Complete `artifacts/worksheet.md` and retain the artifact manifest as reviewable evidence for this lesson.

## OPERATE

Track retrieval misses, stale-source use, unsupported-claim rate and conflicting-source rate.

## GOVERN

Define source ownership, retention and authority rules for high-impact knowledge bases.
