# Lab: RAG Grounding

## Goal
Rank a small corpus and return an answer with source evidence.

## Steps
1. Define inputs, expected output, and explicit stopping conditions.
2. Implement the smallest deterministic version.
3. Add one failure path and test it.
4. Add one security control and one trace event.
5. Measure one quality metric and one operational metric.

## Evidence to submit
Code, tests, one Mermaid diagram, a short risk note, and a reflection on what changes for production.
