# Assessment Framework

| Level | Evidence |
|---|---|
| 1 — Foundation | Explain agent concepts, autonomy, tools, state, RAG, risk and evaluation. |
| 2 — Builder | Implement a bounded single agent with typed tools and tests. |
| 3 — Engineer | Add RAG/memory, multi-step recovery, evaluation and security controls. |
| 4 — Production Engineer | Deploy with configuration, CI, observability, rate/cost controls and runbooks. |
| 5 — Architect | Design enterprise platform boundaries, identity, policy, gateways, evaluation and governance. |
| 6 — AI Leader | Build a value/risk portfolio, ROI/TCO model, operating model and phased transformation roadmap. |

## Rubric
Score each dimension 1–4: 1=insufficient, 2=developing, 3=professional, 4=exemplary.

| Dimension | Professional evidence |
|---|---|
| Knowledge | Correct concepts and trade-offs without framework dependence. |
| Coding | Typed, readable, testable code with clean interfaces. |
| Architecture | Clear boundaries, state, recovery and dependencies. |
| Security | Threat model, least privilege, policy, validation, budgets, approval and isolation. |
| Evaluation | Versioned dataset, metrics, regression tests and release thresholds. |
| Communication | Decisions are concise, traceable and audience-appropriate. |
| Business value | Baseline, KPI, ROI/TCO and adoption assumptions. |
| Production readiness | SLOs, telemetry, rollback, ownership, incident and change process. |
