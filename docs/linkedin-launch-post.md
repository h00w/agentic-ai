# LinkedIn Launch Post — Agentic AI Academy

I have launched **Agentic AI Academy** — an open-source engineering platform for building trustworthy AI agents from first principles through production.

This is not a chatbot demo and not just a course.

The project is designed to show the full engineering system around an agent: architecture, tools, RAG, multi-agent patterns, evaluation, security, observability, governance, release criteria and operational evidence.

The public stack is deliberately separated by function:

- **Hugging Face Playground** — experience bounded agent behavior, RAG, policy decisions and prompt-injection controls.
- **Evaluation & Security Benchmark** — 48 expert-authored synthetic cases across 8 domains including task success, tool routing, groundedness, unsafe actions, policy decisions, multi-agent behavior and regressions.
- **Streamlit Engineering Lab** — inspect benchmark results, traces, RAG evidence, security failures, latency/cost signals, regressions and configurable release-gate decisions.

The architectural principle is simple:

> The model is not the system.

Production trust comes from the control plane around the model: permissions, policy, validation, evaluation, approval, observability, audit and release gates.

The Academy currently includes:

- 14 curriculum modules
- 6 role-based learning pathways
- 10 enterprise case studies
- 10 progressive portfolio projects
- 11 runnable engineering examples
- framework-neutral Python reference implementations
- public evaluation and security benchmark
- live Hugging Face and Streamlit engineering surfaces
- production-readiness, governance and enterprise architecture guidance
