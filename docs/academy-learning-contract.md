# Agentic AI Academy Learning Contract

The Academy teaches trustworthy Agentic AI as a systems-engineering discipline:

```text
UNDERSTAND → BUILD → BREAK → MEASURE → SECURE → SHIP → OPERATE → GOVERN
```

**Framework-later rule:** when practical, teach `minimal mechanism → tests → failure cases → measurement → framework mapping`.

A prompt alone is not sufficient evidence for a production claim. Deep lessons retain code, schemas, Agent Skills, MCP contracts, policies, evaluators, traces, threat models, runbooks, architecture decisions or release evidence.

The public benchmark is part of the curriculum:

```text
lesson → implementation → failure discovered → benchmark case → regression suite → release evidence
```

This contract complements the proof model `L1 Runnable → L2 Reproducible → L3 Capability-Validated → L4 Production-Candidate → L5 Production-Validated`. Lesson completion can generate evidence for those levels but never implies production validation by itself.
