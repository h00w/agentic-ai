# Agent Governance Checklist

- [ ] accountable business owner named
- [ ] system purpose and prohibited uses documented
- [ ] autonomy level and high-impact actions classified
- [ ] data sources, retention and access rules approved
- [ ] tool permissions reviewed under least privilege
- [ ] evaluation dataset and release thresholds versioned
- [ ] security threat model and abuse cases tested
- [ ] human oversight and appeal/escalation path defined
- [ ] telemetry, audit, incident and rollback procedures tested
- [ ] model/provider changes pass regression gates
- [ ] periodic access, risk, KPI and cost review scheduled
- [ ] retirement and data-deletion process defined
