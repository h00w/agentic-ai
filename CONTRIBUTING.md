# Contributing

Thank you for improving Agentic AI Academy. Contributions should be technically correct, safe to run, understandable to the stated learner level, vendor-neutral where practical, and accompanied by tests when code changes behavior.

## Workflow

1. Open an issue or discussion for substantial curriculum or architecture changes.
2. Create a focused branch.
3. Add or update tests and documentation.
4. Run `ruff check .`, `ruff format --check .`, `pytest`, and the example validation script.
5. Avoid committing secrets, local `.env` files, generated credentials, proprietary data, or unsafe host-execution shortcuts.
6. Submit a pull request explaining learning impact, engineering impact, security impact, and verification evidence.

## Curriculum quality bar

Every new lesson should answer: why it matters, what to learn, how to implement it, what can fail, how professionals mitigate those failures, how the skill appears in interviews, how it appears in production, and what the learner should build next.
