# Agentic AI Academy Roadmap

This roadmap keeps the Academy focused on engineering quality, public proof, and responsible scaling rather than uncontrolled feature growth.

## v0.1 — Foundation complete

Status: **completed**

- 14-module curriculum
- six learning pathways
- ten enterprise case studies
- ten portfolio projects
- deterministic examples
- evaluation framework
- security architecture
- production guidance
- observability and governance
- enterprise architecture
- AI leadership pathway
- flagship capstone
- CI, tests, Docker, documentation and diagrams
- professional Academy page at `https://hendarmawan.se/agentic-ai/`

## v0.2 — Interactive public proof

Focus: **Hugging Face + Streamlit**

- launch `h0000w/hendar-agentic-ai` Hugging Face Space

## v1.0 — Professional Academy milestone

Target characteristics:

- stable curriculum structure
- verified beginner-to-architect pathway
- public interactive demos
- reproducible evaluation datasets
- production-ready reference patterns
- enterprise security and governance guidance
- polished capstone demonstration
- complete citation and academic reuse guidance

## Design principles

Every roadmap item should preserve these principles:

1. concepts before frameworks,
2. safe defaults,
3. no unnecessary vendor lock-in,
4. no arbitrary code execution on the host,
5. measurable evaluation,
6. explicit security boundaries,
7. production credibility,
8. understandable beginner examples,
9. architecture depth for advanced learners,
10. responsible enterprise scaling.
