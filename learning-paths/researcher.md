# Researcher Learning Path

**Suggested duration:** Self-paced / 8–12 weeks

Focus on agent architectures, planning, memory, evaluation, multi-agent systems, trustworthy AI, and experimental methodology.

## Sequence
1. [LLM and Agent Foundations](../curriculum/03-llm-agent-foundations/README.md)
2. [Single-Agent Engineering](../curriculum/04-single-agent-engineering/README.md)
3. [RAG, Knowledge and Memory](../curriculum/06-rag-memory-knowledge/README.md)
4. [Multi-Agent Systems](../curriculum/07-multi-agent-systems/README.md)
5. [Agent Evaluation](../curriculum/08-agent-evaluation/README.md)
6. [Security and Safety](../curriculum/09-agent-security/README.md)
7. [Observability and Operations](../curriculum/11-observability/README.md)
8. [Enterprise Agentic AI Architecture](../curriculum/13-enterprise-architecture/README.md)

## Completion evidence
Publish hypotheses, experiment design, datasets, metrics, ablations/failure analysis, limitations and reproducibility evidence.
