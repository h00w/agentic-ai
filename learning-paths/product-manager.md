# AI Product Manager Learning Path

**Suggested duration:** 6 weeks

Focus on use cases, value, workflow design, autonomy, risk, metrics, governance, rollout, ROI, and change management.

2. [LLM and Agent Foundations](../curriculum/03-llm-agent-foundations/README.md)
3. [Tools, APIs and MCP](../curriculum/05-tools-apis-mcp/README.md)
4. [Agent Evaluation](../curriculum/08-agent-evaluation/README.md)
5. [Security and Safety](../curriculum/09-agent-security/README.md)
6. [Governance, Risk and Scaling](../curriculum/12-governance-scaling/README.md)
7. [Agentic AI Leadership and Strategy](../curriculum/14-agentic-ai-leadership/README.md)

## Completion evidence
Create a use-case portfolio, KPI tree, risk register, deployment plan and executive value case.
